Code signing policy

How the Hearth apps are signed, who can release them, and what they send over the network.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What gets signed

The Windows desktop app (Hearth.exe) and its installer (Hearth-Setup-<version>.exe). They are built by GitHub Actions straight from the public source code in the Hearth repository (the workflow is .github/workflows/hearth-apps.yml). Only release builds are signed: version tags, the main branch and builds started by hand. Every signing request is approved by a person before it's signed.

Hearth is open source under the MIT license. Every component it ships is open source too.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

In practice, the desktop app only connects to the Hearth server you choose when you first open it (or the one your community set up for you). It downloads its updates from that same server. If you turn on game or music detection (Settings → Profile → Games & music), it sends the name of the game or song to that server so your friends can see it. Links you click open in your normal web browser.

Reporting a problem

If you think a signed Hearth file was tampered with, or you found a security problem, please open an issue on the GitHub repository (for security problems, see hearth/SECURITY.md first).
