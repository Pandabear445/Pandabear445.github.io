# Hearth API route and permission inventory

> **About this file.** 313 HTTP routes (281 under `/api`, 16 under the bot API `/api/bot/v1`, 16 app-level: files,
> `/media/*`, installs) and 13 `socket.on` handlers (12 events: `disconnect` is registered twice),
> listed from the code at schema 18. The October 2026 audit's baseline had 242 HTTP routes and the same events.
> The Auth, Permission, Validation, Rate limit, Tests and Gaps columns are the auditors' notes on that baseline:
> many "Gaps" have since been fixed (see [ENGINEERING-REPORT.md](ENGINEERING-REPORT.md) and
> [SECURITY.md](../SECURITY.md)), and the "Where" line numbers are current. Routes added after the audit (the
> overhaul's six, then the 49 from the observability, storage, bots and usability workstreams: `/api/health/*`,
> `/api/admin/health`, `/api/admin/alerts*`, `/api/uploads*`, `/api/admin/storage/*`, `/api/me/storage/files`,
> `/api/bots*`, `/api/servers/:id/bots*`, `/api/channels/:id/commands`, saved messages, read state, notification
> preferences, timeouts, pin log, `/api/me/reports` and `/api/me/export*`) have no audit annotations: only "Auth"
> shows `session` where the route lists `auth` itself.
>
> **Bot API.** The 16 routes under `/api/bot/v1` are on their own router (`bapi` in `server/bots.js`, behind
> `botAuth`: a bot token, never a session) and are listed below with the rest; [BOTS.md](BOTS.md) §5 documents them.
>
> **Regenerating.** The list is built by a generator kept with the audit notes, outside this repository. It reads
> every line of `hearth/server/*.js` that starts with `api.`, `app.`, `router.` or `bapi.` followed by a method and a
> path (or a list of paths), and every `socket.on('…')`; it prefixes `/api` for `api.` and `/api/bot/v1` for `bapi.` routes, then attaches the
> auditors' per-area notes by method and path. It rewrites the whole file, so add this note back afterwards.
> Without the generator, `grep -nE "^\s*(api|app|router|bapi)\.(get|post|put|patch|delete)\(|socket\.on\('" server/*.js`
> (run in `hearth/`) lists the same routes and events, plus the SPA fallback (three `/media/*`
> lines register two paths each).

Generated from the code by enumerating every `api.*`/`app.*` route and `socket.on` handler in `hearth/server/*.js`,
then annotated during the security audit (which middleware and checks actually run, limits, tests). "Gaps" lists
what the audit found missing at the time; items fixed since are tracked in [ENGINEERING-REPORT.md](ENGINEERING-REPORT.md).

Routes: 313 HTTP, 13 socket events.
