Hearth vs Discord

A Discord alternative you can run yourself.

Hearth is a free, open-source (MIT) chat app for friend groups and small communities: servers with text and voice channels, roles, threads, DMs and group chats, voice and video with screen sharing, and watching videos together. Messages and files are end-to-end encrypted in the app, and calls are encrypted between the people in them. You can join the public community server, or host your own on a small VPS or a computer at home.

Side by side

The everyday features are much alike. The differences are in who can read what, who runs the server, and what it costs.

HearthDiscord
Messages and files End-to-end encrypted in your app before they're sent, in servers, DMs and group chats. The server stores only encrypted data. Not end-to-end encrypted: Discord's servers can read them.
Voice, video and screen share Encrypted between the people in the call (DTLS-SRTP, with signed handshakes), also when a relay passes the packets along. End-to-end encrypted with its DAVE protocol, rolled out from 2024.
What the server still sees Who is in which server, who talks to whom and when, reactions, server and channel names, profiles and file sizes. The security notes list it all. Everything that isn't end-to-end encrypted, which includes every text message and file.
Ads and paid tiers No ads, and every feature works for everyone. Whoever runs each Hearth decides what supporters who chip in get: a 💜 badge, and optionally more storage and bigger files. Creators can sell memberships to their own community. Free, with a Nitro subscription for extras (bigger uploads, better streams, profile perks) and sponsored Quests.
Self-hosting Yes: one Node.js process and a SQLite file, started with Docker. No outside services needed. No.
Who holds your data Whoever runs the server you're on: you, a friend, or the public community server. Discord.
ID or face checks Hearth never asks for ID documents or face scans, so there's no ID database to leak. Whoever runs each Hearth sets its Terms, including the minimum age. Rolling out age checks worldwide from September 2026: an account Discord can't confirm as adult may be asked for a face scan or an ID. In October 2025 Discord disclosed a breach at a third-party support vendor that exposed some users' ID photos.
Big calls Calls go directly between people, with no media server, so video works best with up to about 4 to 6 cameras on. Voice-only handles more. Media servers carry calls and Go Live streams, so large calls and big audiences work.
IP addresses in calls Because calls go directly between people, everyone in a call can see each other's IP address, and anyone allowed to join a voice channel can collect them. A call switched to a region (a relay the server's owner runs) goes through that relay only, so people in it see the relay's address instead, unless that relay stops answering and the call falls back to connecting directly. The server always sees everyone's. Details. Media servers sit between people, so people in a call don't see each other's IP address. Discord sees everyone's.
Bots and integrations Bots with slash commands, signed outgoing webhooks, incoming webhooks that take Discord- and Slack-style posts (Uptime Kuma, Home Assistant, Grafana, GitHub), and a news bot for feeds. Bot posts are marked as not end-to-end encrypted. A huge ecosystem of bots and integrations.
Apps Any browser, installable on every system; desktop apps for Windows, Mac and Linux and an Android app, built by each server's owner (GitHub Actions) and downloaded from that server's own page, not from an app store. On iPhone it's the installable web app (with notifications). Windows, Mac, Linux, Android, iOS and the web.
Profiles A full MySpace-style page for everyone, free: themes, a profile song, top 8, a comment wall and your own CSS. Profile decorations, effects and more customisation come with Nitro or from the Shop.

Bring your Discord server

Moving a community is mostly about structure, and Hearth can copy that for you.

Add a server → Import from Discord starts a new server from a Discord server template: its roles, categories, channels and channel permissions. Hearth shows you how to copy the template in your browser (it never contacts Discord or asks for a Discord login), and before anything is created it lists what won't come over and anything Hearth would allow that Discord didn't.

Members, messages and emoji don't come with it yet. Everyone joins through an invite link, which can expire and have a use limit. The full mapping is in IMPORT.md.

When to pick something else

Hearth is built for friend groups and small communities. Some needs are better served elsewhere (as of October 2026):

Matrix (Element)

If you need federation, where people on servers run by different people talk to each other, or bridges to other chat networks. Hearth has neither, on purpose: a bridge has to decrypt messages to pass them on.

TeamSpeak

If what you mostly want is voice for gaming, with many people in one channel.

Stoat (formerly Revolt)

If you want a Discord-style service that someone else hosts and runs for you.

Staying on Discord

If your community depends on large video calls, streaming to big audiences, public server discovery or a particular bot.

Honest limits

Self-hosting communities ask these first, so here they are.

  • The server sees metadata: who talks to whom and when, even though it can't read what's said.
  • The app's code comes from the server. The web, desktop and Android apps load it from the server you use, so you're trusting whoever runs it not to change that code. That's true of any web app; pick a server you trust, or host your own.
  • No federation or bridges, by design.
  • Group video doesn't scale to big calls (see the table).
  • People in a call can see each other's IP address, because calls go directly between people, unless the call is switched to a region (a relay the server's owner runs; in a server, anyone with Manage Channels can switch it). If that matters to your community (doxxing, attacks on someone's home connection), set up a region and use it, or only let people you trust into voice channels. See SECURITY.md §4.
  • No independent security audit yet. The threat model and every known limit are in SECURITY.md.
  • How it's built: most of the code is written with an AI coding assistant, and the commit history shows which changes were. Every change runs the automated test suite in CI, including a suite of attacks against the server and the encryption.
